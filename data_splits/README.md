# Dataset Manifests and Published Outer Splits

The image files themselves are not included.

- `fruits_manifest.csv`: relative image identifier, class, optional sample group, filename for the 10,901-image Fruits run.
- `fruits_outer_splits.csv`: exact outer development/test membership for all five folds.
- `kth_tips_manifest.csv`: relative image identifier, class, optional sample group, filename for the 810-image KTH-TIPS run.
- `kth_tips_outer_splits.csv`: exact outer development/test membership for all five folds.

Absolute workstation paths were deliberately removed before public release. This does not change image identity or fold membership.
